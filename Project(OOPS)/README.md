# Student Information Management System

A simple console-based Student Information Management System developed using C++ and Object-Oriented Programming (OOP).

## Features

- Add Student
- Display Students
- Search Student
- Update Student Information
- Delete Student
- Exit

## Technologies Used

- C++
- Object-Oriented Programming (OOP)
- Git
- GitHub

## Project Functionalities

### 1. Add Student
Allows the user to add a new student's information such as:
- Name
- Roll Number
- Age
- Course
- Marks

### 2. Display Students
Displays the information of all students stored in the system.

### 3. Search Student
Searches for a student using their Roll Number.

### 4. Update Student
Allows the user to update existing student information.

### 5. Delete Student
Allows the user to delete a student using their Roll Number.

## How to Run

1. Clone the repository.
2. Open the project in VS Code.
3. Compile the C++ program.
4. Run the generated executable.
